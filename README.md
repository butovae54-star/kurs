# Дело о четырёх решениях

Интерактивный курс по безопасной работе с ИИ-инструментами. Тридцать экранов, шесть упражнений, финальный тест. Артефакт для портфолио разработчика электронных курсов.

## Что это

Одностраничное приложение без сборки: три файла, открываются в любом браузере. Никакого Node.js, npm и сборщиков — можно просто открыть `index.html`.

Сюжет: в понедельник утром выясняется, что презентация для тендера оказалась в открытом доступе. Доступ к файлу был у четырёх человек, взлома не было. Курс — реконструкция четырёх решений, каждое из которых казалось разумным.

## Структура

```
index.html    — разметка, шапка, подвал
styles.css    — дизайн-токены и все стили
content.js    — ВЕСЬ ТЕКСТ КУРСА (править только здесь)
app.js        — движок: навигация, упражнения, сохранение прогресса
README.md
```

Контент отделён от кода: чтобы поменять формулировки, правьте `content.js`. Логику трогать не нужно.

## Локальный запуск

Просто откройте `index.html` двойным щелчком. Всё работает, включая сохранение прогресса.

Если нужен локальный сервер (некоторые браузеры строже относятся к `file://`):

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Публикация на GitHub Pages

1. Создайте на GitHub новый **публичный** репозиторий. **Бесплатный хостинг GitHub Pages для приватных репозиториев не работает.**
2. Загрузите в него `index.html`, `styles.css`, `content.js`, `app.js` и `README.md` — в корень, без вложенных папок.
3. В репозитории: **Settings → Pages**.
4. В блоке «Build and deployment» выберите **Source: Deploy from a branch**, **Branch: main**, папку **/ (root)**. Нажмите **Save**.
5. Подождите 1–3 минуты. Сайт появится по адресу:

```
https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/
```

Если репозиторий называется `ВАШ-ЛОГИН.github.io`, адрес будет короче: `https://ВАШ-ЛОГИН.github.io/`.

Сборка не нужна, поэтому никаких GitHub Actions и настроек `base` — это частая причина пустой страницы в проектах на Vite, но здесь такая проблема невозможна.

## Публикация на Netlify (альтернатива, 1 минута)

Откройте app.netlify.com/drop и перетащите всю папку с файлами. Получите ссылку сразу, без аккаунта. Для портфолио лучше всё же завести бесплатный аккаунт, иначе сайт может быть удалён.

## Что внутри

**Экраны:** титул, сюжетные сцены, имитация мессенджера, документы с поиском проблемных фрагментов, сортировка карточек по уровням данных, выбор варианта с разбором последствий, чек-лист допуска инструмента, финальный тест.

**Упражнения:** поиск зон в документе (2 экрана), сортировка карточек (2 экрана), выбор варианта (7 экранов), чек-лист (1 экран), тест из 6 вопросов.

**Механика:** прогресс в `localStorage`, счётчик верных решений (12 максимум), тест с проходным баллом 80% и двумя попытками, сохранение и сброс прогресса.

## Авторский режим

Shift+D или адрес с `#dev` открывает панель со списком экранов: можно прыгнуть на любой и сбросить прогресс. При обычном прохождении панель не видна.

## Доступность и мобильность

- Работает с клавиатуры: Tab, Enter, Space
- Фидбэк объявляется через `aria-live`
- Фокус переходит на заголовок экрана при переходе
- Уровни риска различаются цветом, иконкой и подписью — не только цветом
- Целевая ширина 375px, горизонтального скролла нет
- Учитывается `prefers-reduced-motion`

## Что можно улучшить

- Добавить экран с итоговым разбором ошибок теста
- Вынести тексты в JSON и подгружать через fetch (тогда понадобится сервер, не `file://`)
- Добавить экспорт результата прохождения в PDF для отчёта руководителю
